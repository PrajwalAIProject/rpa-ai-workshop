# Code of Conduct

## Our pledge

We want everyone taking part in this workshop and its repository — students, facilitators,
faculty, and contributors — to have a welcoming, harassment-free experience, regardless of
age, background, ability, or level of experience.

## Our standards

Examples of behavior that help build a positive environment:

- Being respectful and patient, especially with people new to these tools.
- Giving and gracefully accepting constructive feedback.
- Focusing on what is best for the learning community.

Examples of unacceptable behavior:

- Harassment, insults, or derogatory comments.
- Publishing others' private information without permission.
- Any conduct that would be inappropriate in a classroom or professional setting.

## Scope

This Code of Conduct applies within all project spaces — the repository, issues, and pull
requests — and whenever someone is representing the project in public spaces.

## Enforcement

Instances of unacceptable behavior may be reported to the repo maintainer via GitHub
issues. All reports will be reviewed and handled as fairly and promptly as possible.
Maintainers may remove, edit, or reject contributions that do not align with this Code of
Conduct.
